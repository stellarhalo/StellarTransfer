# StellarTransfer

StellarTransfer 是基于 [stonith404/pingvin-share](https://github.com/stonith404/pingvin-share) 的分支项目。

本项目在原有自托管文件分享能力的基础上，对前端首页和上传流程进行了定制。前端页面的视觉风格参考了“奶牛快传”的设计语言，包括首页入口、文件上传面板、取件码展示与接收文件交互等体验。
